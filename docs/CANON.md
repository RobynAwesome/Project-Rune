# Canon — Project Rune / KPGS

Status: glossary and naming hygiene for public RUNE docs. Local Schematics remain the GSMB vault; this file is the cloud-facing canon surface.

## Glossary

| Concept | Canonical form | Notes |
|---|---|---|
| **GSMB** | Governance System Main Brain | SSE-locked acronym. “Membrane” is metaphor for perimeter/wall only — **not** the expansion of GSMB. |
| **KPGS** | Kopano / KC governance stack surrounding GSMB | Operating doctrine, protocols, FoC immune system. |
| **VOC** | Validation of Concept | Parent of PoC / FoC. |
| **PoC** | Proof of Concept | Success / validation branch. |
| **FoC** | Failure of Concept / Freedom of Concept | Immune groups that grow as new failure patterns are recognized. Do **not** collapse to “Full Operational Capability” in RUNE docs. |
| **RUNE** | Runtime Unified Network **Endorsement** | Never “consensus.” |
| **Endorsement** | Independently issued, checkable attestation | Verifier outside the subject’s own judgment. |
| **Consensus** | Mutual agreement among parties | Insufficient for high-risk gate clearance. |
| **Gate** | Fail-closed enforcement point | Checks for a valid signed ledger record, not agent rhetoric. |
| **Ledger** | Append-only endorsement / gate receipt log | Receipts first; narratives second. |
| **Jethro triage** | Green / Yellow / Red escalation | Named KPGS hook; see WORKFLOWS. |

## Membrane vs Main Brain

- **Main Brain (GSMB):** the governance system itself — doctrine, immune system, constitutional hub.
- **Membrane (metaphor):** the perimeter / publish boundary. Schematics stay local metal (often gitignored). Project-Rune is the deliberate cloud surface that publishes governance doctrine without merging dirty OneDrive trees into “Rune done.”

## Status claims

| Claim | Allowed when |
|---|---|
| `PENDING` / `ENDORSED` / `REJECTED` / `REVOKED` | Ledger statuses only |
| `COMPLETE` / `PROVEN` / `DEMO READY` | Owner verification **and** ledger receipt for that completion subject |

Agents must not write completion statuses without an endorsement covering `completion_claim`.
